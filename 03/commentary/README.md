# Commentary — Unit 03: Richard Stallman

This directory is the annotation layer for Unit 03. There is no single primary codebase here — the unit is a constellation: GNU Emacs, GCC (already in `02/`), GDB, the GPL licenses themselves. The commentary lives alongside all of them.

---

## Structure

```
commentary/
├── README.md          ← you are here
├── vision.md          ← the extended frame for the unit
├── manifesto.md       ← close reading of the GNU Manifesto (1985)
├── gpl.md             ← the GPL as literature: v1, v2, v3 as a narrative arc
├── emacs.md           ← Emacs as philosophy expressed in architecture
├── gdb.md             ← GDB as infrastructure; the debugger as political act
└── connections.md     ← the thread running through all eleven units
```

---

## The difference from other units

Units 01 and 02 centered on specific codebases. This unit centers on a *person* and the *ideas* that person generated — with codebases as evidence and illustration rather than primary text.

The primary texts here are the documents: the GNU Manifesto, the GPL licenses, the Emacs manual's preface, Stallman's philosophical essays. The code confirms and embodies the ideas; the documents state them.

Reading order: manifesto first, then licenses, then code. Not the other way around.

---

## Voice

Same as the rest of the course: opinionated, precise, written to be read. These documents take positions. They say what matters. They note where things are contested without pretending the contests don't exist.

Stallman is controversial as a person. The ideas are not. The commentary is about the ideas.
