The prophet. The printer. The four freedoms. The legal and moral infrastructure of free software.

Richard Stallman's story begins with a printer he couldn't fix because the manufacturer wouldn't release the source code. He decided the correct response was to spend the rest of his life building an alternative — a complete free operating system, a legal instrument to protect it, and a philosophical argument for why software freedom is a moral necessity.

The GNU Project produced Emacs, GCC, GDB, Bison, and the GPL. These tools are the foundation that Linux runs on. Without Stallman's work, the open source ecosystem that built the web would not exist.

## Materials

- **Emacs** (`emacs/`) — the editor as operating system. Sparse checkout of `src/` and core Lisp files.
- **GDB** (`gdb/`) — the GNU Debugger. Read a running program's memory, set breakpoints, trace execution.
- **Bison** (`bison/`) — the parser generator. The tool that builds the tools.
- **GNU Manifesto** (`scratch/gnu-manifesto.txt`) — 1985. The founding document of the free software movement.
- **GPL v1, v2, v3** (`scratch/`) — the legal instrument that makes copyleft work. Read all three and watch the argument evolve.
- **doctor.el** (`scratch/doctor.el`) — Emacs's ELIZA implementation. A psychotherapist in 300 lines of Lisp.
- **BUILD-emacs.md** (`scratch/`) — how to build Emacs from source
- **lisp-exercise.md** (`scratch/`) — introduction to Emacs Lisp through the codebase
- **gdb-exercise.c** (`scratch/`) — a program to debug, step by step
