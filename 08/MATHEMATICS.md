## What is a hole?

This is not a trivial question.

A circle has a hole. A disk does not. A torus has two kinds of holes —
the one you go through and the one the tube goes around. A sphere has
a hole of a higher kind: the void it encloses.

But "hole" is not a mathematical definition. It is an intuition.
Homology is the machinery that makes the intuition precise.

The key insight, due to Henri Poincaré (1895) and formalized by Emmy Noether
in the 1920s: a hole is a *cycle that is not a boundary*.

---

## Simplices: the building blocks

A **0-simplex** is a point.

```
 •
 0
```

A **1-simplex** is an edge (a line segment between two points).

```
 0 ──── 1
```

A **2-simplex** is a filled triangle.

```
      2
     / \
    /   \
   0 ─── 1
```

A **3-simplex** is a solid tetrahedron.

In general, an **n-simplex** is the convex hull of n+1 points in general position.
For our purposes, a simplex is just a sorted tuple of integer vertex labels.

A **face** of a simplex is any simplex you get by dropping one or more vertices.
The faces of (0,1,2) are (0,1), (0,2), (1,2), (0,), (1,), (2,).

---

## Simplicial complexes

A **simplicial complex** K is a collection of simplices such that:
- Every face of a simplex in K is also in K.
- The intersection of two simplices in K is a face of both.

In practice: you give us the maximal simplices, and we include everything smaller.

```python
K = SimplicialComplex([(0,1,2), (1,2,3)])
# Automatically includes:
#   (0,1), (0,2), (1,2), (1,3), (2,3)
#   (0,), (1,), (2,), (3,)
```

Example complexes:
- A triangle (boundary only): (0,1), (1,2), (0,2)
- A filled triangle: (0,1,2)
- A tetrahedron (hollow): (0,1,2), (0,1,3), (0,2,3), (1,2,3)
- A tetrahedron (solid): (0,1,2,3)

## Orientation

To compute homology, we need to orient our simplices.

An oriented n-simplex is a tuple of vertices with an ordering.
Two orderings that differ by an even permutation are the same orientation;
odd permutations flip the sign.

For edges: [0,1] = −[1,0]. The edge from 0 to 1 is the negative of the edge
from 1 to 0. This makes sense geometrically: they point in opposite directions.

For our purposes: simplices are represented as sorted tuples, and the sign of
a face is determined by which vertex was omitted.

---

## The boundary map

The boundary of a simplex is the alternating sum of its faces.

**∂₁ (boundary of an edge):**
```
∂[0,1] = [1] − [0]

    −        +
    0 ──────▶ 1
```

The head gets +1, the tail gets −1. The boundary of an arrow is its tip minus
its tail.

**∂₂ (boundary of a triangle):**
```
∂[0,1,2] = [1,2] − [0,2] + [0,1]
```

That is: the boundary of a triangle is the sum of its three edges,
with signs chosen so that the boundary goes around the triangle consistently.

The general formula:

    ∂[v₀, v₁, ..., vₙ] = Σ_{l=0}^{n} (−1)^l [v₀, ..., v̂_l, ..., vₙ]

where v̂_l means the l-th vertex is omitted.

---

## The key fact: ∂∂ = 0

The boundary of a boundary is always zero.

```
∂₁(∂₂([0,1,2])) = ∂₁([1,2] − [0,2] + [0,1])
                 = ([2]−[1]) − ([2]−[0]) + ([1]−[0])
                 = [2]−[1]−[2]+[0]+[1]−[0]
                 = 0
```

The boundary of a triangle is a closed loop. And the boundary of a closed
loop is empty (no endpoint).

This is not a miracle. It is a calculation. But it is the calculation
that makes homology possible.

## Chain groups and chain complexes

The **n-th chain group** C_n is the free abelian group generated by the
oriented n-simplices. A *chain* is a formal integer linear combination
of simplices.

For the circle (three edges and three vertices):
```
C_1 = ℤ{(0,1)} ⊕ ℤ{(0,2)} ⊕ ℤ{(1,2)}   ← three edges
C_0 = ℤ{(0,)} ⊕ ℤ{(1,)} ⊕ ℤ{(2,)}       ← three vertices
```

The boundary maps arrange these into a **chain complex**:

```
0 → C_n → C_{n-1} → ... → C_1 → C_0 → 0
         ∂_n              ∂_1
```

with the property ∂_{n-1} ∘ ∂_n = 0.

---

## Homology groups

Given the chain complex, define:
- **Z_n = ker(∂_n)**: the n-cycles (chains whose boundary is zero)
- **B_n = im(∂_{n+1})**: the n-boundaries (chains that are boundaries of something)

Since ∂∂ = 0, every boundary is a cycle: B_n ⊆ Z_n.

The **n-th homology group** is:

    H_n = Z_n / B_n = ker(∂_n) / im(∂_{n+1})

This measures how many cycles fail to be boundaries — how many
"holes" exist that are not "filled in."

**H_0** counts connected components.
**H_1** counts independent loops (one-dimensional holes).
**H_2** counts enclosed voids (two-dimensional holes).

---

## The computation: boundary matrices and Smith normal form

Each boundary map ∂_n is a linear map between free abelian groups —
a matrix of integers.

For the circle (vertices 0,1,2; edges (0,1), (0,2), (1,2)):
```
∂₁ =        (0,1)  (0,2)  (1,2)
       (0,)  [ -1    -1     0  ]
       (1,)  [  1     0    -1  ]
       (2,)  [  0     1     1  ]
```

To compute H_n from this matrix, we use **Smith normal form**.

Any integer matrix M can be written as M = UDV where U, V are invertible
integer matrices and D is diagonal with d₁ | d₂ | ... | d_r.

The diagonal entries d_i are the **invariant factors**.

From the invariant factors:
- rank(∂_n) = r_n (number of nonzero invariant factors)
- Betti number: β_n = k_n − r_n − r_{n+1}
  where k_n = number of n-simplices
- Torsion: Z/d_iZ for each invariant factor d_i > 1 of ∂_{n+1}

## Working out the circle by hand

Circle K: vertices (0,), (1,), (2,). Edges (0,1), (0,2), (1,2).
No triangles.

**Step 1**: Write ∂₁ (3×3 matrix, rows=vertices, cols=edges).

```
        (0,1)  (0,2)  (1,2)
(0,) [  -1     -1      0  ]
(1,) [   1      0     -1  ]
(2,) [   0      1      1  ]
```

**Step 2**: Compute Smith normal form of ∂₁.

Via row/column operations over ℤ (like Gaussian elimination, but using
the Euclidean algorithm instead of division):

After reduction: diagonal [1, 1, 0]. Invariant factors: [1, 1]. Rank = 2.

**Step 3**: ∂₂ = 0 (no triangles). Rank = 0.

**Step 4**: k₁ = 3 (three edges).

β₁ = k₁ − rank(∂₁) − rank(∂₂) = 3 − 2 − 0 = **1**.

**Step 5**: k₀ = 3 (three vertices).

β₀ = k₀ − rank(∂₀) − rank(∂₁) = 3 − 0 − 2 = **1**.

(∂₀ = 0 since there are no (−1)-simplices.)

**Result**: H₀ = ℤ, H₁ = ℤ. One component, one loop. ✓

## The standard spaces and their homology

| Space          | H₀ | H₁         | H₂ | χ |
|----------------|----|------------|-----|---|
| Point          | ℤ  | 0          | 0   | 1 |
| Interval       | ℤ  | 0          | 0   | 1 |
| Circle S¹      | ℤ  | ℤ          | 0   | 0 |
| Sphere S²      | ℤ  | 0          | ℤ   | 2 |
| Torus T²       | ℤ  | ℤ²         | ℤ   | 0 |
| Klein bottle   | ℤ  | ℤ ⊕ ℤ/2ℤ  | 0   | 0 |
| RP²            | ℤ  | ℤ/2ℤ       | 0   | 1 |
| Möbius band    | ℤ  | ℤ          | 0   | 0 |

The torsion in H₁(RP²) = ℤ/2ℤ says: there is a loop that is not a boundary,
but going around it *twice* gives a boundary. This corresponds to the fact
that RP² is non-orientable: you can return to your starting point having
flipped your orientation.

## The Euler characteristic

The **Euler characteristic** χ(K) can be computed two ways:

**Combinatorially:** χ = Σ (−1)^n · (number of n-simplices)

**Topologically:** χ = Σ (−1)^n · β_n

These always agree. This is the **Euler-Poincaré formula**.

For Euler's original observation (1758): for any convex polyhedron,
V − E + F = 2. This is χ(S²) = 2.

Euler noticed the pattern. Poincaré understood what it counted.
Noether gave it the algebraic machinery that made computation possible.

## Where to go next

The computation in `08/python/` and `08/haskell/` computes homology with
coefficients in ℤ. There are many directions to extend:

- **Coefficients in ℤ/2ℤ** — simpler arithmetic, useful for non-orientable spaces
- **Cohomology** — the dual theory; the cup product gives ring structure
- **Persistent homology** — vary a parameter, track how holes appear and disappear
- **Simplicial sets** — a more general categorical framework
- **Singular homology** — extends homology to arbitrary topological spaces, not just simplicial complexes

**Hatcher's *Algebraic Topology*** (free PDF from his website) covers all of this.
Chapter 2 is where we are. Chapter 1 is the easier prerequisites.
Chapter 0 is the part that looks hard but repays rereading.
