# A Garden of Languages

*In time, we expect to build simplices in most of these.*

---

Languages are not neutral. Each one is an argument about what programming is — what thinking is. The same simplicial complex, expressed in twenty languages, is not the same twenty times. It is twenty different answers to the question: what is a boundary?

Read these not as a taxonomy but as a cast of characters. Some are old and strange and difficult. Some are young and eager. Some are famous for the wrong reasons. A few are almost forgotten. They are all alive.

---

## The Imperative Family
*From the void, through the machine, through BASIC and C*

**Assembly** — The bottom. No abstractions. Registers, addresses, jumps. Building simplices here is like carving stone — slow, exact, and you feel every edge. The machine is not hiding anything from you.

**FORTRAN** (1957) — The first. Formula Translation. Built for scientists who needed to talk to the machine without becoming machine operators. Still alive in numerical computing. Your boundary matrix will run faster than you deserve.

**BASIC** (1964) — Democracy. Kemeny and Kurtz wanted everyone to have it. For a decade it was the first language of millions of children — including people who went on to build the world. Numbered lines, GOTO, and the radical idea that the computer was for you.

**C** (1972) — The foundation. Ritchie built it to write Unix. Forty years later it still runs the world's infrastructure. Implementing simplices in C means you are responsible for your own memory. The boundary map will not clean up after itself. Neither will anything else.

**Pascal** — Wirth's discipline. Clean, structured, pedagogically honest. Where many people first learned that programs could be reasoned about, not just executed.

**C++** (1985) — C with ambitions. Stroustrup added objects, then templates, then more templates. The language that power plants and games and browsers are written in. A city that grew without a plan. Simplices here are possible, elaborate, and slightly too large.

**Java** (1995) — The enterprise. Gosling's write-once-run-anywhere. Verbose by design. The language of institutions. Somewhere in the world a bank is running boundary map calculations on a Java server that has not been restarted since 2011.

**Go** (2009) — Google's answer to C++. Simple, fast, concurrent. Opinionated about what it will not do. Goroutines and channels. Simplices in Go are clean and a little boring, which is a compliment.

**Rust** (2015) — Safety without garbage collection. The borrow checker as a theorem prover built into the compiler. Implementing homology in Rust means the compiler has opinions about your boundary maps. It is usually right.

## The Lisp Family
*From Church's lambda calculus, through McCarthy, through the parenthesis*

**Lisp** (1960) — McCarthy's five pages. Code is data. The interpreter bootstraps itself. One of the great moments in the history of thought — a complete programming language derived from a mathematical logic paper. The original simplices were lists of lists.

**Scheme** (1975) — Lisp with a conscience. Steele and Sussman stripped it down and made it beautiful. *The Structure and Interpretation of Computer Programs* is written in Scheme. Tail recursion guaranteed. A small and perfect language.

**Racket** — Scheme with batteries and a pedagogical mission. The language of *How to Design Programs*. Has a full macro system, a teaching IDE, and more dialects than any language has a right to. The boundary operator in Racket is a function that returns a list of cons cells, and this is fine.

**Common Lisp** — The big one. An attempt to unify the Lisp dialects of the 1980s. Has everything, which means it has too much of everything. Used by people who know exactly why they are using it.

**Clojure** (2007) — Lisp on the JVM. Hickey's gift: immutability by default, persistent data structures, running inside Java's ecosystem. Simplices as vectors. Boundary maps as pure functions. Very satisfying.

**Emacs Lisp** — The language Stallman wrote to make Emacs programmable. Not a beautiful Lisp. Powers one of the most powerful text editors ever made. Your simplicial complex can live inside your editor.

## The ML Family
*Type theory made executable*

**ML** (1973) — Milner's language for theorem proving. Gave us type inference: the compiler figures out the types, you write the program. The simplest boundary map has a type, and the compiler knows it before you do.

**OCaml** — ML with objects added (mostly ignored) and a fast native compiler. The language of Jane Street's trading systems and many theorem provers. Algebraic data types that make a Simplex feel natural.

**Haskell** (1990) — Pure functional. Lazy evaluation. Monads. The language that takes type theory seriously. Your boundary map is a function from Chain to Chain and the types will stop you from making errors that Python would let through silently. Learning Haskell changes how you think about every other language.

**Elm** — Haskell's cheerful younger cousin, living in the browser. No runtime exceptions. A narrow language that does its one job with unusual care.

**F#** — ML on the .NET runtime. Microsoft's functional language. Takes the ML tradition and runs it inside the enterprise. A reasonable place to implement simplices if you live in that world.

---

## The Proof Languages
*Programs as proofs. The code is the argument.*

**Coq** — A proof assistant written in OCaml. The Curry-Howard correspondence made executable: types are propositions, programs are proofs. You can prove that your boundary map satisfies ∂∂ = 0 and the computer will check the proof.

**Agda** — Dependent types. The code and the proof are the same text. A simplicial complex in Agda is a mathematical object that has been verified to exist. Reading Agda is reading mathematics being made rigorous in real time.

**Lean** (Lean 4) — The modern proof assistant. Mathlib runs on it. The community is building all of mathematics inside it. Simplicial homology exists in Mathlib already — reading the Lean source is a different kind of understanding than implementing it yourself.

**Idris** — Dependent types with a focus on programming, not just proving. Quantities track how many times a variable is used. The boundary operator has a type that enforces its own properties.

---

## The Scripting Family
*Fast, expressive, built to get things done*

**Perl** (1987) — Larry Wall's three virtues: laziness, impatience, hubris. Perl mirrors natural language — gnarly, flexible, expressive in the way that natural language is expressive. The boundary operator in Perl can be written many ways and all of them work.

**Python** (1991) — Readability as a value. Guido's great argument: code is read more than it is written. Our starting language for simplices. The chain complex is a dictionary. The boundary map is a function. NumPy handles the linear algebra.

**Ruby** (1995) — Matz designed it for programmer happiness. Said so explicitly. A transmission of Japanese craft ethics into a programming language. Blocks, everything is an object, the principle of least surprise. Elegant simplices.

**Lua** (1993) — Small, embeddable, readable. Built to be extended and to extend. Tables are the only data structure, and tables are enough. Used in games, in embedded systems, in everything that needs a scriptable core. Blender has a Lua-adjacent soul.

**JavaScript** (1995) — Ten days to write, thirty years to live with. Brendan Eich's fast sketch became the language of the web. Async, event-driven, prototype-based. Simplices in the browser, rendered with WebGL, connected to the DOM. Inclusive by accident.

**PHP** — The web's most used and least loved language. Powers more of the internet than anyone admits. Implementable simplices, real history, no apologies.

**Tcl** — Tool Command Language. Everything is a string. Small, strange, older than it looks. John Ousterhout built it to glue other programs together. A curiosity that earned its place.

---

## The Array Languages
*APL lineage: notation as thought*

**APL** (1962) — Iverson's mathematical notation made executable. Operators that work on whole arrays. A complete program in three symbols. Reading APL requires a font with characters that do not appear in ordinary text. The boundary matrix is a one-liner.

**J** — APL with ASCII characters. Iverson's second attempt, with Roger Hui. The same power, different symbols. The simplicial complex collapses to an expression.

**K / Q** — The financial derivatives. Used in high-frequency trading. Array processing at extreme speed. The boundary map runs before you have time to worry about it.

**Julia** (2012) — Modern scientific computing. Fast like C, expressive like Python, with multiple dispatch that makes mathematical structures natural. The language that numerical mathematicians actually want. Simplices in Julia feel like mathematics.

---

## The Logic Family
*Computation as deduction*

**Prolog** (1972) — Logic programming. You state what is true; the machine figures out what follows. The simplicial complex is a set of facts. The boundary map is a rule. Backtracking handles the search. A completely different relationship between programmer and machine.

**Mercury** — Prolog with types and determinism. The logic programming language that takes correctness seriously.

**Datalog** — Prolog stripped to its relational core. Used in program analysis and databases. Simplices as relations, boundary maps as recursive rules.

---

## The Concurrent Family
*Multiple things at once*

**Erlang** (1986) — Built at Ericsson for telephone switches that cannot go down. Lightweight processes, message passing, let-it-crash philosophy. A simplicial complex distributed across a hundred nodes.

**Elixir** — Erlang's modern descendant. The same beam virtual machine, a cleaner surface. Phoenix framework. Warm community. The boundary map as a GenServer.

---

## The Stack Languages
*Forth and its descendants: radical minimalism*

**Forth** (1970) — Charles Moore's single-person language. A stack, a dictionary of words, nothing else. Implementable on any hardware by one person in a weekend. Walden written in concatenative code. The boundary map is a word that consumes a simplex and leaves its faces on the stack.

**PostScript** — The language inside your printer. Stack-based, Turing-complete, used to draw every page of text that came out of a laser printer for thirty years. A simplicial complex can be drawn directly, without going through an application.

**Factor** — A modern concatenative language with an image-based development environment. Forth's ideas, brought forward.

---

## The Statistical Family
*Where mathematics meets data*

**R** (1993) — Statisticians talking to each other in code. A strange language with a devoted community. Linear algebra built in. The boundary matrix is a matrix already.

**MATLAB / Octave** — The engineer's scratchpad. MATLAB is commercial; Octave is the free alternative. Matrices are the native type. Simplices as sparse matrices, boundary maps as linear transformations. What engineers reach for.

**S** — The ancestor of R. Bell Labs again. John Chambers. The source of the tradition.

---

## The Domain-Specific and Visual
*Languages with a world inside them*

**Blender Python** — Our visual witness. The simplicial complex rendered in 3D space. Walk around it. See the hole that H₁ is counting. Python scripts that drive a 3D engine, producing geometry from abstract algebra. This is the language that makes the mathematics visible.

**Processing** — Casey Reas and Ben Fry's visual language for artists and designers. Java underneath, but you do not need to know that. Drawing simplices on a canvas, animating the boundary map.

**GLSL / HLSL** — Shader languages. Run on the GPU, in parallel, for every pixel on screen. The geometry passes through these on its way to your eye. The topological structure of what Quake renders lives partly here.

**SQL** — Structured Query Language. Not usually called a programming language, but it is one. Relational. Declarative. The simplicial complex as a database. The boundary map as a join. Strange and powerful and everywhere.

---

## The Esoteric and the Minimal
*Languages that ask: what is the minimum?*

**Brainfuck** (1993) — Eight characters. Turing-complete. The simplest possible language that can compute anything. Implementing simplices here is an act of endurance and philosophy. It has been done.

**Befunge** — A two-dimensional language. The program counter moves in four directions. The code is a grid. Topology in the structure of the program itself.

**Piet** — Programs written as bitmap images. The color and the shape of the image are the code. A boundary map as a painting.

---

## A Note on This List

This is not complete. No such list could be. There are languages for music (SuperCollider, ChucK), languages for hardware (VHDL, Verilog), languages for the web (TypeScript, Elm, ClojureScript), languages invented by one person for private use and never named. The garden keeps growing.

What they share: someone thought carefully about what computation should feel like, made a decision, and built a world around it. Reading simplices across languages is reading those decisions — what each language considers natural, what it makes hard, what it reveals that the others hide.

The mathematics does not change. The light changes.
