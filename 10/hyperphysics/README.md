## What it is

HyperPhysics is a physics reference built as a concept map — every topic links to adjacent topics, and the links have defined meaning. You navigate it the way you navigate a mind, not the way you navigate a textbook. It covers the full range of undergraduate physics: mechanics, thermodynamics, electromagnetism, optics, atomic and nuclear physics, relativity, and more.

Rod Nave built and maintained it essentially alone over several decades. That it is still a top resource — still the first result for countless physics searches — is a direct consequence of the tool he used to structure it.

## Why it's here

HyperPhysics was built using the successor technologies to HyperCard, Apple's 1987 hyperlinking system. HyperCard gave authors a way to build card-based networks where links had defined semantic meaning — you knew what a link *meant* because the tool had a contract. Nave could build and maintain thousands of interconnected pages alone because the system encoded the structure, not him.

This is the lesson Unit 10 draws from HyperPhysics: the difference between a system with a defined linking contract (HyperCard, Zettelkasten) and one without (the open web). The web inherited the link but not the meaning. HyperPhysics predates the attention economy and was never optimized for search — it was optimized for understanding. That is why it still works.

It also sits in a lineage that runs through this course: the card as unit of thought (Zettelkasten), the card as unit of computation (HyperCard), the concept map as navigation (HyperPhysics), the network as server (BitTorrent), influence from connectivity alone (PageRank). These are not separate ideas. They are the same idea in different registers — what Norbert Wiener called cybernetics: information, feedback, and structure as prior to content.

## How to read it

Open `hyperphysics.phy-astr.gsu.edu/hbase/hframe.html` in a browser. Follow any link that interests you. Notice that every page is short — one concept, clearly stated, with links to what you need to understand it and to what it leads. Notice that you never feel lost. That is not an accident. That is the design.

Then ask: what would the web look like if it had been built this way?
