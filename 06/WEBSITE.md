Before C, there was assembly. Before assembly, there were punch cards. Before punch cards, there was a loom.

Unit 06 traces the history of programming languages as a history of notation — of finding better ways to write instructions for machines. The unit begins with Ada Lovelace's Note G (1843, the first program) and ends with Haskell's type system. The line from the Jacquard loom to lambda calculus is real and unbroken.

The primary texts are the papers: Church (1936), Turing (1936, 1950), McCarthy (1960), Lovelace (1843). These are the founding documents of computation. The code — assembly, BASIC, Haskell — implements what the papers describe.

## Materials

- **LANGUAGES.md** — survey of programming language families with opinionated commentary
- **GHC** (`ghc/`) — the Glasgow Haskell Compiler. Sparse checkout of the type checker and core. The most sophisticated type system in wide use.
- **NASM** (`nasm/`) — the Netwide Assembler. Where the machine becomes readable.
- **hello-world.asm** (`scratch/`) — assembly for x86: the smallest possible program
- **hello-basic.bas** (`scratch/`) — BASIC: the language that put programming in front of a generation
- **Turing 1936** (`scratch/turing-1936.pdf`) — "On Computable Numbers." The paper that invented computation.
- **Turing 1950** (`scratch/turing-1950.pdf`) — "Computing Machinery and Intelligence." Can machines think?
- **Lovelace 1843** (`scratch/lovelace-notes.txt`) — Note G from the Analytical Engine translation. The first program.
