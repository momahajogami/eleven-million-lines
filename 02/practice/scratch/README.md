# Scratch

Write test programs here. Compile them against `../tcc/tcc` or the system `gcc`.

```bash
# From this directory:
../tcc/tcc hello.c -o hello && ./hello
../tcc/tcc -run hello.c          # compile-in-memory and run directly
gcc hello.c -o hello-gcc && ./hello-gcc
```

Nothing here is precious. Delete and rewrite as needed.
