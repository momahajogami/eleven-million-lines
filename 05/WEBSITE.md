No one knows what coding is. That is not a failure of definition. It is the most interesting fact about it.

Unit 05 reads coding as a cultural act: TeX as Knuth's obsession with beauty, BitTorrent as Cohen's insight that the network itself is the server, GIMP as a demonstration that the open source model produces real tools, PageRank as the eigenvector that organized human knowledge. The unit also follows SourceForge — from idealist commons to adware distributor — as a cautionary arc that Unit 10 and Unit 11 will echo.

Skateboarding culture runs as a parallel thread: DIY ethics, spot ownership, making in public. The comparison illuminates both.

## Materials

- **CULTURE_AND_SPECTACLE.md** — the unit argument: coding as cultural production
- **EIGENRANK.md** — PageRank as eigenvector: Brin, Page, and the mathematics of knowing what matters
- **GIMP** (`gimp/`) — GNU Image Manipulation Program. Sparse checkout of `app/` and `plug-ins/`.
- **LaTeX2e** (`latex2e/`) — Knuth's typesetting system. The tool this course's documents would be set in.
- **libtorrent** (`libtorrent/`) — a C++ implementation of the BitTorrent protocol
- **Pure Data** (`pure-data/`) — Miller Puckette's visual programming language for audio and multimedia
- **BitTorrent spec** (`scratch/bittorrent-spec.txt`) — the protocol as a document, like RFC 2616
