### Populating unit 03 (Stallman/GNU)

**Cloned GNU Emacs and GDB using blobless sparse checkouts:**

```bash
# Blobless clone: downloads commit/tree objects but not file contents yet.
# This is fast and small. You fill in files on demand with sparse-checkout.
git clone --filter=blob:none --no-checkout https://github.com/emacs-mirror/emacs.git 03/emacs
git clone --filter=blob:none --no-checkout https://sourceware.org/git/binutils-gdb.git 03/gdb

# Sparse checkout: tell git which directories you actually want on disk.
cd 03/emacs
git sparse-checkout init
git sparse-checkout set src/ lisp/simple.el lisp/subr.el lisp/startup.el lisp/emacs-lisp/ README
git checkout HEAD

cd ../gdb
git sparse-checkout init
git sparse-checkout set gdb/ include/ README
git checkout HEAD
```

Why `--filter=blob:none`: large repos like Emacs (full history ~1GB) become
manageable (~240MB) because git only fetches the object graph, not every
file version ever committed. The files you sparse-checkout are fetched
on demand.

Why `--no-checkout`: skips writing any files to disk immediately. You then
control exactly what lands with `sparse-checkout set`.

**Downloaded FSF primary texts with curl:**

```bash
# Follow redirects (-L), save to file (-o)
curl -sL https://www.gnu.org/licenses/old-licenses/gpl-1.0.txt -o 03/scratch/gpl-1.0.txt
curl -sL https://www.gnu.org/licenses/old-licenses/gpl-2.0.txt -o 03/scratch/gpl-2.0.txt
curl -sL https://www.gnu.org/licenses/gpl-3.0.txt              -o 03/scratch/gpl-3.0.txt

# Strip HTML tags to get plain text (sed removes anything between < and >)
curl -sL "https://www.gnu.org/gnu/manifesto.html" \
  | sed 's/<[^>]*>//g' \
  | sed '/^[[:space:]]*$/d' \
  > 03/scratch/gnu-manifesto.txt
```

The `sed 's/<[^>]*>//g'` pattern: `<[^>]*>` matches any HTML tag (opening
`<`, then any characters that aren't `>`, then closing `>`). The `g` flag
replaces all occurrences on each line.

Files fetched: gpl-1.0.txt, gpl-2.0.txt, gpl-3.0.txt, gnu-manifesto.txt,
free-software-definition.txt, why-open-source-misses-the-point.txt,

### The simplicial homology implementation

`07/scratch/simplicial_homology.py` is original course content. It computes
simplicial homology over ℤ/2ℤ from scratch.

**The mathematics in one paragraph:**
A simplicial complex is a collection of vertices, edges, triangles, etc.,
closed under taking faces. The boundary operator ∂ maps each n-simplex to
the sum (mod 2) of its faces. The key fact: ∂∘∂ = 0. The n-th homology group
is ker(∂ₙ) / im(∂ₙ₊₁). Over ℤ/2ℤ, this reduces to Gaussian elimination on
{0,1} matrices. The Betti numbers βₙ = dim(ker ∂ₙ) - dim(im ∂ₙ₊₁) count
connected components (β₀), loops (β₁), voids (β₂), etc.

**To run it:**
```bash
cd 07/scratch
python simplicial_homology.py
```

All outputs verified: circle β₁=1, sphere β₂=1, torus β₀=1 β₁=2 β₂=1,
RP² β₁=1 β₂=1 over ℤ/2ℤ. Euler characteristic consistent throughout.

### Moving SIZES.md and creating meta/

```bash
# git mv preserves history (the file wasn't deleted and recreated — it was moved)
git mv SIZES.md meta/SIZES.md
```

The difference between `git mv` and `mv` + `git add`: `git mv` stages the
rename atomically. `mv` followed by `git rm old` + `git add new` achieves
the same result but is more steps.

### Committing

The pattern used throughout:

```bash
# Stage specific files/directories (never `git add .` — too easy to include
# things you didn't mean to)
git add 03/emacs/ 03/gdb/ 03/scratch/gpl-1.0.txt ...

# Heredoc for multiline commit messages (avoids shell quoting nightmares)
git commit -m "$(cat <<'EOF'
feat: short summary line

Longer description here.
More detail.

Co-Authored-By: Claude Sonnet 4.6 <noreply@anthropic.com>
EOF
)"
```

The `'EOF'` with single quotes prevents shell expansion inside the heredoc.
Without quotes, `$variables` and backticks would be interpreted by the shell.

## Things to learn before next session

These are the techniques used today. Each one is worth understanding well
enough to do from memory.

**1. Blobless sparse checkout** — the core pattern for adding large repos:
```bash
git clone --filter=blob:none --no-checkout URL DIR
cd DIR
git sparse-checkout init
git sparse-checkout set PATH1 PATH2 ...
git checkout HEAD
```
Practice: clone any large public repo this way and inspect the result.
Check `.git/info/sparse-checkout` to see what was written.

**2. `curl -sL URL -o FILE`** — the flags matter:
- `-s` silent (no progress bar)
- `-L` follow redirects (many URLs redirect; without this you get HTML)
- `-o FILE` write to file (without this it prints to stdout)

**3. Stripping HTML with sed:**
```bash
curl -sL URL | sed 's/<[^>]*>//g' | sed '/^[[:space:]]*$/d' > output.txt
```
The first sed removes tags. The second removes blank lines.
Understand the regex: `[^>]*` means "zero or more characters that are not `>`".

**4. git mv vs mv** — for moving tracked files, always use `git mv` so the
rename is staged correctly and history is preserved.

**5. Heredoc commit messages** — `$(cat <<'EOF' ... EOF)` is the cleanest
way to write multiline git commit messages from the command line without
escaping nightmares.

**6. Simplicial homology** — run `simplicial_homology.py`, read the docstring,
then try to reconstruct the `boundary_matrix` function from scratch.
The boundary operator is the heart of it: drop each vertex of a simplex in
turn, collect the faces. Over ℤ/2ℤ, signs don't matter.
