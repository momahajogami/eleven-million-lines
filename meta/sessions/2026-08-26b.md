### Unit 09 — Tetris implementation

Wrote a playable, readable Tetris in Python (~120 lines) using the `curses` library.
No external dependencies. Terminal-native.

```bash
python3 09/other-games/tetris/tetris.py
# Controls: a/d move, w rotate, s drop, q quit
```

Key design decisions:
- `rotate()`: (r,c) → (c,−r), then normalize to origin — a 2D linear transformation in 4 lines
- `clear_lines()`: `pop` the full row, `insert([0]*COLS)` at top — list mutation is the gravity
- `[]` characters match Pajitnov's original Electronika 60 display (no graphics, just text)

### Unit 08 — Full simplicial homology implementation

The main work of the session. A complete, tested simplicial homology library in Python,
mirrored in Haskell. 17 files, 1886 lines, 47 tests, all passing.

**Python (08/python/):**
- `simplicial.py` — `SimplicialComplex`: give it maximal simplices, gets all faces
- `boundary.py` — `boundary_matrix(K, n)`: rows = (n−1)-simplices, cols = n-simplices
- `smith.py` — `smith_factors(M)`: Euclidean algorithm extended to matrices
- `homology.py` — `HomologyGroup`, `homology(K, n)`, `all_homology(K)`
- `examples.py` — circle, sphere, torus, Klein bottle, RP², Möbius band
- `tests/test_homology.py` — 47 tests

```bash
cd 08/python
python examples.py          # see all standard spaces
python -m pytest tests/ -v  # run 47 tests
```

**Key mathematical subtlety caught by tests:**
Smith normal form of diag(2,3) is [1,6], not [2,3]. Smith form requires d₁|d₂.
Since 2∤3, the algorithm correctly reduces to [1,6]. Z/2Z ⊕ Z/3Z ≅ Z/6Z by CRT.
The test expectation was wrong; the code was right.
