## Things to learn before next session

- **udisksctl**: mounts drives as a regular user without sudo. `udisksctl mount -b /dev/sda1` — useful when sudo is unavailable or the password is unknown.
- **fstab**: add the drive's UUID entry so it mounts automatically on boot. `lsblk -f` shows UUIDs.
- **KDE Power Management**: System Settings → Power Management → Energy Saving → set "Suspend session" to Never. Prevents the machine from sleeping and losing the mount.
- **sudo password reset via GRUB**: if the sudo/root password is lost, boot to GRUB, press `e`, append `systemd.unit=rescue.target` to the `linux` line, boot, then run `passwd ralph`. On LVM systems the volumes should be available in rescue mode.
