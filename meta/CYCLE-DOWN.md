# Cycling Down

At the end of each session, write a dated file in `meta/sessions/YYYY-MM-DD.md`.

The log is not a changelog. It is a tutorial written for a future Ralph who wants to understand what happened well enough to do it again without help. Write the commands. Explain the flags. Say why, not just what.

---

## Template

```
# Session YYYY-MM-DD

## What we were trying to do

## What we actually did (with commands)

## Things to learn before next session

## Pending for next session

## Open questions
```

---

## The discipline

The goal of this log is transfer. Every session, something got built. The question this log answers is: could you build it again, alone, starting from scratch?

If the answer is no — write more. If the answer is yes — you have internalized it. That is the point.
