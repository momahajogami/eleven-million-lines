Unit 02

Classical Coding

C compilers, vi/vim, git — and the character of Linus Torvalds.

The tools of the Unix tradition: DMR's C compiler, tcc, early GCC. The editor wars begin with Bill Joy and vi. Then git — written by Linus in two weeks because he needed it. LINUS.md is a character study.

Materials

  • tcc — Fabrice Bellard's tiny C compiler
  • gcc — early GCC
  • vim — Bram Moolenaar's editor
  • git — Linus Torvalds, 2005
  • LINUS.md — character study
  • practice/ — exercises
