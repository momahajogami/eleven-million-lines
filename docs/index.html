You Should Know

A course in reading landmark codebases

Code is writing. People wrote it. You can read it too.
Eleven codebases. Eleven units. One tradition.

Syllabus

  • 01 Early Unix xv6, Unix v6, Plan 9 — the place where most of what you use was invented
  • 02 Classical Coding C compilers, vi/vim, git — and the character of Linus Torvalds
  • 03 Richard Stallman GNU, the GPL, Emacs, GDB — the prophet and the four freedoms
  • 04 Blender The heroic story — art, architecture, and the community buyout
  • 05 Culture, Spectacle and Eigenrank TeX, BitTorrent, SageMath, PageRank — coding as writing augmented with electricity
  • 06 Languages and Theory BASIC, Assembly, LISP, Haskell — from Lovelace's 1843 notes to Church and Turing
  • 07 The Spiritual Grothendieck, Lawvere — the mathematics that underlies the mathematics
  • 08 Simplicial Homology by Hand Build the chain complex from scratch — Python, Haskell, markdown as thinking layer
  • 09 Quake and the Grammar of Games Wolfenstein, Doom, Quake — BSP trees, fast inverse square root, Carmack's .plan files
  • 10 Browsers and Social Media Mosaic, Firefox, WebKit — the social graph as data structure
  • 11 Large Language Models Attention Is All You Need, nanoGPT — what does it mean to read code that produces language?
