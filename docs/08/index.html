Unit 08

Simplicial Homology by Hand

The mathematics lives in the markdown. The code is its expression.

Unit 08 builds simplicial homology from scratch — vertices, edges, faces, boundary maps, homology groups — first in plain English, then in Python, then in Haskell. The theorem does not care what language you use. That is the lesson.

This is the sandbox unit. It is artistic and inclusive. The talented beginner builds comprehensible structures from first principles. The markdown file is the persistent thinking layer: it crosses languages the way a sketchbook crosses media. You write down what a simplicial complex is. Tomorrow you open that file in a different language and implement it again. The topology was there before Python or Haskell existed.

Unit 08 is where pure abstraction (Unit 07) meets the computational (Unit 09). Grothendieck gave us the structural language. Carmack built a game with it — without knowing it.
